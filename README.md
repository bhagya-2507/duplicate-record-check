
# Duplicate Record Check

## About the Project

This project was developed as part of the VEDA Technology Data Analytics Track.

The objective is to identify duplicate records in the Sample Superstore dataset using Python Pandas and Microsoft Excel.

## Objectives

- Identify duplicate records.
- Analyze data quality.
- Generate a duplicate record report.
- Create a cleaned dataset.
- Document the data cleaning process.

## Technologies Used

- Python
- Pandas
- Microsoft Excel
- Jupyter Notebook

## Project Workflow

1. Load the dataset.
2. Check duplicate records in Excel.
3. Load the dataset using Pandas.
4. Identify complete duplicate rows.
5. Generate a duplicate report.
6. Export the cleaned dataset.

## Project Files

- Duplicate_Record_Check.ipynb
- Duplicate_Report.xlsx
- Cleaned_Superstore.xlsx

## Result

The project checks complete duplicate rows and generates a report documenting the results.
